راهنمای ساخت و نصب نسخهٔ ویندوز
HAMI Download Manager (HDM) v1.0.1 — HAMI SMART SYSTEMS
════════════════════════════════════════════════════════

دو برنامه لازم است — هر دو رایگان:
──────────────────────────────
۱) Python 3.12      → https://www.python.org/downloads/windows/
۲) Inno Setup 6     → https://jrsoftware.org/isdl.php


مراحل ساخت
──────────
۱) نصب پایتون: تیک ☑ Add python.exe to PATH را حتماً بزن → Install Now
۲) نصب Inno Setup 6 با پیش‌فرض‌ها
۳) این پوشه را Extract کن در یک مسیر ساده مثل C:\HDM  (مسیر فارسی نباشد)
۴) build_windows.bat را اجرا کن  (پایتون، PyInstaller و PyQt6 را نصب و برنامه را می‌سازد)
      خروجی:  dist\HDM-1.0.1\HDM-1.0.1.exe
۵) build_installer.bat را اجرا کن  (یا روی hdm_setup.iss راست‌کلیک → Compile)
      خروجی:  installer\HDM-1.0.1-Setup.exe
   (اگر در PyInstaller خطای آیکون یا version گرفتید، build_windows.bat خودکار با
    hdm_simple.spec دوباره تلاش می‌کند.)


نصب روی ویندوز
──────────────
• اجرای HDM-1.0.1-Setup.exe → Next → نصب در Program Files
• میانبر در منوی استارت، آیکون در Apps & features، و Uninstall
• تیک «Create a desktop shortcut» → آیکون روی دسکتاپ
• تیک «Start HDM with Windows» → اجرا با ویندوز (در نوار سیستم، بی‌صدا)


امکانات برنامه
──────────────
• دانلود تکه‌تکه: هر فایل به ۸ تکه تقسیم می‌شود، همزمان دریافت می‌شود و در پایان
  یک فایل کامل تحویل داده می‌شود (مانند IDM). با توقف و ادامه، هر تکه از همان‌جا
  که مانده ادامه می‌یابد. ستون «تکه‌ها» تعداد آن را نشان می‌دهد.
• صف دانلود (بخش Download queue و نیز Settings → Options → Queue):
     – Pause Queue / Resume Queue  (مخصوص کل صف، جدا از دکمه‌های هر فایل)
     – Start Now : ادامهٔ همهٔ دانلودهای ناتمام، حتی اگر زمان‌بندی فعال باشد
     – گزینهٔ «ادامهٔ دانلودهای ناتمام هنگام اجرای برنامه» برای بعد از بستن و باز کردن
• Settings → Options… :
     – تعداد دانلود همزمان: ۱ تا ۵ (پیش‌فرض ۳)
     – دسته‌بندی خودکار فایل‌ها در پوشه‌ها
     – زمان‌بندی: دانلود فقط بین ساعت … تا …
     – انتخاب پوشهٔ دانلودها
• پوشه‌بندی خودکار در  ~/Downloads/HDM :
     Programs (exe/msi/apk/…) · Compressed (zip/rar/7z/iso/…)
     Video (mp4/mkv/…) · Photo (jpg/png/…) · Music · Documents · Others
• کلیپ‌بورد: با اجرای برنامه و با کلیک در کادر آدرس، لینک کپی‌شده خوانده می‌شود؛
  در Settings → Options می‌توانید گزینهٔ «شروع خودکار با کپی شدن لینک» را روشن کنید
• افزونهٔ مرورگر: کروم، اج و فایرفاکس — راهنما در «راهنمای-نصب-افزونه-مرورگرها.txt»
• Settings → Language : English / فارسی
• بستن پنجره = رفتن به نوار سیستم (کنار ساعت) و ادامهٔ دانلود؛
  خروج کامل: راست‌کلیک روی آیکون → Quit  یا  File → Exit


لایسنس و فعال‌سازی
──────────────────
• بالای پنجره همیشه وضعیت را می‌بینید:
     «نسخهٔ آزمایشی — ۷ روز باقی‌مانده»  یا  «فعال‌شده — مادام‌العمر / یک‌ساله · ۳۰۰ روز باقی‌مانده»
  وقتی دورهٔ آزمایشی تمام شود: سرعت محدود به ۱۵۰ کیلوبایت/ثانیه.
• فعال‌سازی: منوی Help → «Activate license…»  یا  About → «Activate…»
  (کادر فعال‌سازی از پایین برنامه حذف شده است)
• در پنجرهٔ About: وضعیت (فعال — مادام‌العمر / شش‌ماهه / یک‌ساله)، تاریخ پایان،
  شمارش معکوس زنده، و شناسهٔ دستگاه.
• یادآوری: ۷ روز مانده و دوباره ۱ روز مانده به پایان، پیام می‌دهد.
• قفل سخت‌افزاری: لایسنس به مادربرد/پردازنده/بایوس همین دستگاه قفل می‌شود.
     – کپی کردن فایل لایسنس روی کامپیوتر دیگر → بی‌اعتبار
     – دست‌کاری فایل لایسنس یا عقب کشیدن تاریخ سیستم → بی‌اعتبار
     – نصب دوبارهٔ ویندوز روی همان دستگاه → با همان نام و کلید دوباره فعال می‌شود
• کادر پایین برنامه حذف شد؛ دکمهٔ Activate در About و منوی Help است.
• فعال‌سازی اینترنتی (هر سریال فقط یک کامپیوتر):
     پوشهٔ hdm-activate-server را روی سرور نصب کنید (راهنما داخل همان پوشه).
     آدرس سرورها در فایل endpoints.json کنار برنامه است.
     اگر اینترنت نبود، تا ۱۴ روز به‌صورت آفلاین کار می‌کند و بعد نیاز به تأیید دارد.

فروش لایسنس (cmd داخل پوشه)
──────────────────────────
   python gen_license.py "نام خریدار" 6m      → ۵۸۰,۰۰۰ تومان
   python gen_license.py "نام خریدار" 1y      → ۱,۱۰۰,۰۰۰ تومان
   python gen_license.py "نام خریدار" life    → ۵,۰۰۰,۰۰۰ تومان
نام + کلید را با هم بفرست. gen_license.py را پیش مشتری نفرست.
دورهٔ آزمایشی: ۷ روز سرعت کامل، بعد ۱۵۰ کیلوبایت/ثانیه.


اگر ارور گرفتید
──────────────
• «python is not recognized» → پایتون دوباره نصب شود با تیک Add to PATH
• «Inno Setup 6 not found» → نصب نشده؛ بعد از نصب دوباره build_installer.bat
• ارور pip → در cmd:  python -m pip install --upgrade pyinstaller pillow PyQt6
• آنتی‌ویروس exe را پاک کرد → Allow / Restore (فایل امضا نشده است)
• آیکون عوض نشد → Task Manager → Windows Explorer → Restart
• هر ارور دیگر: متن پنجره را کپی کن و بفرست
